Privacy Policy

Last updated: 2 November 2026

1. About this application

Zwift Stream Manager is an independently developed personal Windows project used to prepare, inspect and manage YouTube livestream workflows for JRØNE / TeamNL Zwift Racing. It uses YouTube API Services. Some write operations are disabled during development.

2. Data accessed

With the account holder's OAuth consent, the app may access YouTube channel identity and broadcast details, including livestream identifiers, titles, descriptions, scheduling, visibility and lifecycle status. Depending on features explicitly enabled, it may prepare metadata and thumbnail updates. Local components may process Zwift event metadata and streaming preferences. Local signup indications are not treated as externally verified RSVPs.

3. Purpose

These data are used to identify the authorised channel, avoid duplicate broadcasts, inspect schedules and support authorised livestream management. The app does not request or store a YouTube account password.

4. Storage and sharing

OAuth tokens, local event records, configuration and logs may be stored on the operator's Windows computer. This static website receives no OAuth tokens or YouTube API data and does not operate an account database. Authorised requests are transmitted to Google/YouTube. Personal information is not sold to advertisers. GitHub Pages may process ordinary website access logs.

5. Retention and removal

Local YouTube API-derived data are to be refreshed or removed when no longer required, according to applicable YouTube API Services policies and their data retention requirements. Local backups must also be reviewed for deletion requests. Contact the maintainer below for assistance reviewing or deleting locally stored authorised data.

6. Revoking access

Access can be revoked in Google Account connections. Revoking permission prevents subsequent authorised API requests but does not itself delete YouTube broadcasts or existing local data.

7. Website tracking

These static pages use no analytics scripts, advertising pixels or site-created tracking cookies. The hosting provider may keep operational logs. See also the Google Privacy Policy.

8. Contact

For privacy questions, revocation assistance or local data deletion requests: jeroen.diepenbroek@gmail.com.

9. Changes

This policy may change as development progresses. Material changes to the application's data practices will be described before related functionality is enabled.

Independent software project. Using its YouTube API features is also subject to the YouTube Terms of Service.
