What the project does

◉

Race preparation

Organises locally available race information, scheduling choices and event metadata for the stream workflow.

▣

YouTube integration

Uses authorised YouTube API access to inspect existing broadcasts and support livestream planning and management.

↗

Stream presentation

Supports a separate desktop streaming setup, including race metadata and thumbnail preparation.

Development status. Zwift Stream Manager is a private, evolving project. Some automated actions are disabled while safety checks, authorisation and approval workflows are being developed. This website does not provide an online account or connect to YouTube itself.
